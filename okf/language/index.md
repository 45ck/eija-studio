# Ubiquitous language: the domain terms the kernel is built around

# Ubiquitous Language Terms

* [Authority](authority.md) - Permission to perform a domain or governance operation at the moment it commits.
* [Change Case](change-case.md) - Aggregate linking one original request to interpretations, chosen meaning, baseline, candidate, transactions, receipts and decision.
* [Effect Intent](effect-intent.md) - A transactionally queued synthetic notification or audit append.
* [Evidence Receipt](evidence-receipt.md) - A dated local verifier observation set attached to technical subject dimensions.
* [Local Decision](local-decision.md) - A capability-checked acknowledgement of an exact subject, scope, current baseline and answers.
* [Meaning Selection](meaning-selection.md) - A local owner's explicit choice of one canonical supported interpretation.
* [Preview Instance](preview-instance.md) - One isolated persisted execution of the candidate model.
* [Review Packet](review-packet.md) - A derived view of the current subject, blockers, technical claims, raw receipts, affected nodes and critical questions.
* [Semantic Transaction](semantic-transaction.md) - One typed business-meaning edit.
* [Workflow Definition](workflow-definition.md) - Immutable typed states/transitions/roles/guards/effect declarations.
