## Notes

The protected generic policy: coherence with the pack's declared action catalog (guards, required effects, forbidden effects) plus the pack's laws ([domain.laws](/modules/domain/laws.md)), and the only path by which transactions become a model (`apply_transactions`). Change it only with a regression test and an ADR: the tests treat weakening a guard, role or effect as a failure, and the release fixture will report a source mismatch that requires owner review.
