# Visual model

Status as of 2026-09-29: **open PR #6, not on `main`.** Goal: a reviewer of an agent's change sees the ripple through the models, not just a code diff. Diagrams are generated projections of the executable model ([ADR-0019](../adr/0019-diagrams-generated-from-executable-model.md), `proposed`).

## What is on `main` today

* Rules, state cards and journey text derived from the executable transitions (`domain.policy.projections`), so they cannot disagree.
* A fixed-point impact closure over the model (`domain/impact.py`).
## Added by the oss lane (open PR #14, on `main` only when it merges)

* The [README](https://github.com/45ck/eija-studio#a-visual-example-generated-from-the-real-model) before/after state diagram and impact list, generated by `scripts/gen_readme_diagram.py` from `domain.policy` and `domain.impact` and checked for drift by nox session `readme_diagram`.

## What the visual lane adds (not yet on `main`)

* Mermaid, PlantUML and Graphviz DOT generated deterministically from the typed `Workflow` and the impact graph, pinned by golden-file tests.
* A semantic before/after diff with a legend, and a Studio "Visual" view.
* A generated diff image at `docs/assets/visual-diff.png`, which will replace the README example.

Owns `src/eija_studio/resources/web/`. Nobody edits a rendered diagram as a source of truth.

Planned after it, in wave 2: drag-and-drop UML that issues typed semantic transactions, and a DDD tree of the ubiquitous language. See the [roadmap](../ROADMAP.md).
